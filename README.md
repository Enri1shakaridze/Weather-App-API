# Weather App

A simple and modern weather application UI built with HTML and CSS.

## Features

- Search weather by city name
- Clean and modern design
- Displays:
  - Temperature
  - Weather condition
  - Humidity
  - Wind speed
- Responsive card layout

## Technologies Used

- HTML5
- CSS3

## Preview

The application displays weather information for a selected city, including temperature, humidity, and wind speed in an attractive user interface.
